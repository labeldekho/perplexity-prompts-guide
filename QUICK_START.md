# 🚀 Quick Start Guide

Get up and running with Perplexity AI in 5 minutes.

---

## Step 1: Understand the Basics

**Perplexity is NOT ChatGPT.** It's a search engine that:
- Searches the internet first, then synthesizes
- Provides citations for every claim
- Excels at finding recent, factual information

**Key insight:** Think "Google with AI synthesis" not "ChatGPT with citations"

---

## Step 2: Your First Effective Prompt

### ❌ Don't Do This
```
Tell me about artificial intelligence
```
**Why it fails:** Too broad, no context, returns generic overview

### ✅ Do This Instead
```
Latest breakthroughs in multimodal AI models after January 2024, 
focusing on peer-reviewed papers from top-tier conferences
```
**Why it works:** Specific topic + time constraint + source filter

---

## Step 3: Master the 3-Part Prompt Formula

Every effective Perplexity prompt has three elements:

```
[SPECIFIC TOPIC] + [TIME/SOURCE CONSTRAINT] + [OUTPUT REQUIREMENT]
```

### Examples:

**Research:**
```
Tesla's battery technology developments [TOPIC]
after Q3 2024 [TIME]
from industry publications only [SOURCE]
```

**Competitive Intelligence:**
```
OpenAI's enterprise pricing strategy [TOPIC]
compared to Anthropic and Google [COMPARISON]
with evidence from official announcements [SOURCE]
```

**Academic:**
```
Meta-analyses on intermittent fasting [TOPIC]
published in last 2 years [TIME]
from journals with impact factor > 5 [SOURCE]
```

---

## Step 4: Use Progressive Deepening

Don't try to get everything in one prompt. Instead:

### Round 1: Map the Landscape
```
Overview of quantum computing applications in drug discovery
```

### Round 2: Drill Down
```
Focus on the protein folding applications mentioned. 
Which companies are leading this space?
```

### Round 3: Get Specific
```
Compare D-Wave and IBM's approaches to protein folding. 
What are the key technical differences?
```

**Why this works:** Each round builds on previous context, narrowing focus progressively.

---

## Step 5: Demand Evidence

Always ask for citations and evidence:

### Basic Prompt
```
What are the benefits of remote work?
```

### Evidence-Driven Prompt
```
What are the benefits of remote work according to peer-reviewed studies? 
Cite specific findings with page numbers and publication dates.
```

**Result:** Verifiable claims instead of generic synthesis.

---

## Step 6: Use Focus Modes

Switch modes mid-conversation to redirect search behavior:

- **Academic** → Peer-reviewed journals only
- **Writing** → Creative and editorial content
- **Video** → YouTube and video sources
- **Social** → Reddit, Twitter/X, LinkedIn discussions
- **Finance** → Market data, company filings

**How to use:** Click the Focus dropdown before your prompt, or switch mid-conversation to pivot.

---

## Step 7: Validate Results

Perplexity can still hallucinate. Always:

1. **Check citations** - Click through to source pages
2. **Look for consensus** - Multiple sources saying the same thing
3. **Verify quotes** - Search exact quotes on the source page
4. **Cross-check** - Use ChatGPT/Claude to verify claims

**Red flags:**
- Single obscure blog as only source
- No direct quotes or page numbers
- Claims that seem too convenient

## Practice Exercise

Try this workflow right now:

1. **Pick a topic** you're genuinely curious about
2. **Write a vague prompt** (like you'd use on Google)
3. **Rewrite it** using the 3-part formula
4. **Run both** in Perplexity and compare results
5. **Follow up** with 2-3 progressive deepening questions

---

## Common Mistakes to Avoid

| Mistake | Why It's Bad | Fix |
|---------|-------------|-----|
| Too vague | Returns generic info | Add specific context |
| No time constraint | Gets outdated sources | Specify "after [date]" |
| Asking for opinions | Perplexity fetches facts | Ask for "perspectives from [sources]" |
| Long instructions | Over-constrains search | Keep it concise, search-like |
| Trusting single sources | Risk of misinformation | Demand multiple sources |
