# Fact-Checking Template

A systematic approach to verifying claims using Perplexity.

---

## Template

### Step 1: Identify the Claim
```
Claim to verify: "[EXACT CLAIM]"

Source of claim: [WHERE YOU FOUND IT]
Date: [WHEN IT WAS MADE]
```

### Step 2: Find Original Source
```
Find the original source for this claim: "[CLAIM]"

I need:
- Primary source (not secondary reporting)
- Exact quote or data
- Publication date and context
- Author credentials
```

### Step 3: Find Corroborating Evidence
```
Find at least 3 independent sources that address this claim: "[CLAIM]"

For each source:
- What they say (exact quotes)
- Their evidence or methodology
- Publication date
- Source credibility

Prioritize: Official sources, peer-reviewed research, established news organizations
```

### Step 4: Find Contradictory Evidence
```
Find sources that contradict or challenge this claim: "[CLAIM]"

Include:
- Contradictory findings
- Critiques of methodology
- Alternative interpretations
- Fact-checker assessments

Cite specific sources.
```

### Step 5: Assess Context
```
What important context is needed to understand this claim: "[CLAIM]"?

Consider:
- Time period (is it still current?)
- Geographic scope (does it apply everywhere?)
- Population (who does it apply to?)
- Conditions or caveats
- What the claim doesn't say
```

### Step 6: Verdict
```
Based on the evidence, assess this claim: "[CLAIM]"

Provide:
- Verdict: True / Mostly True / Mixed / Mostly False / False / Unverifiable
- Confidence level: High / Medium / Low
- Key evidence supporting verdict
- Important caveats or nuances
- Sources used in assessment
```

## Example: Fact-Checking a Statistic

### Claim
"Remote workers are 13% more productive than office workers"

### Step 1: Identify
```
Claim: "Remote workers are 13% more productive than office workers"
Source: LinkedIn post
Date: January 2024
```

### Step 2: Original Source
```
Find the original source for "13% productivity increase" for remote workers.

I need:
- Original study or report
- Exact methodology (how was productivity measured?)
- Sample size and composition
- Publication date and venue
- Full context of the finding
```

### Step 3: Corroborating Evidence
```
Find 3+ independent studies on remote work productivity.

For each:
- Productivity change found (%, direction)
- How productivity was measured
- Sample characteristics
- Study design (experiment, survey, etc.)
- Publication details

Do they support the 13% figure?
```

### Step 4: Contradictory Evidence
```
Find studies showing different results about remote work productivity.

Include:
- Studies showing no change or decrease
- Critiques of positive findings
- Methodological concerns
- Moderating factors (job type, etc.)
```

### Step 5: Context
```
What context is needed for the "13% more productive" claim?

Consider:
- What type of work was studied?
- How was productivity measured?
- Short-term vs long-term effects?
- Self-reported vs objective measures?
- What factors weren't controlled for?
```

### Step 6: Verdict
```
Verdict: MIXED

Confidence: MEDIUM

Evidence:
- Original claim likely from Stanford study (Bloom et al.)
- Study found 13% increase, but only for call center workers
- Other studies show mixed results depending on job type and measurement
- Self-reported productivity often higher than objective measures
- Long-term effects less clear than short-term

Caveats:
- Claim is accurate for specific context (call center, specific company)
- Not generalizable to all remote work
- Measurement method matters significantly
- Individual variation is high

Sources: [List specific papers and reports]
```

## Quick Fact-Check (Simplified)

For quick checks, use this condensed version:

```
Verify: "[CLAIM]"

Find:
1. Original source and context
2. At least 2 corroborating sources
3. Any contradictory evidence
4. Expert consensus (if exists)

Assess: True / Partially True / False / Unverifiable
Confidence: High / Medium / Low
Key caveat: [Most important context]
```

---

## Tips for Effective Fact-Checking

### ✅ DO:
- Find primary sources, not secondary reporting
- Check publication dates (claims can become outdated)
- Look for methodology (how was it determined?)
- Seek multiple independent sources
- Consider context and caveats
- Note confidence level honestly

### ❌ DON'T:
- Trust single sources
- Accept claims without checking original
- Ignore contradictory evidence
- Forget to check dates
- Over-simplify nuanced findings
- Confuse correlation with causation
