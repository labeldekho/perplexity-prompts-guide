# Research Workflow Template

A reusable template for conducting comprehensive research on any topic.

---

## Template Structure

### Phase 1: Landscape Mapping
```
Overview of [TOPIC] after [DATE]

Focus on:
- Key concepts and definitions
- Main approaches or schools of thought
- Leading researchers or organizations
- Recent developments

Sources: [SPECIFY SOURCE TYPES]
```

### Phase 2: Deep Dive
```
Focus on [SPECIFIC ASPECT] of [TOPIC]

Find:
- Detailed explanations or mechanisms
- Evidence and data
- Methodologies used
- Contradictions or debates

For each claim, cite specific sources with dates.
```

### Phase 3: Comparative Analysis
```
Compare [APPROACH A] vs [APPROACH B] for [TOPIC]

For each:
- Core principles
- Evidence supporting it
- Limitations or criticisms
- Use cases or contexts where it excels

Highlight key differences and trade-offs.
```

### Phase 4: Gap Identification
```
What aspects of [TOPIC] are under-researched or poorly understood?

Identify:
- Questions current research doesn't answer
- Methodological limitations
- Contradictions that need resolution
- Future research directions proposed

Cite researchers who acknowledge these gaps.
```

### Phase 5: Synthesis
```
Based on the research above, what can we confidently conclude about [TOPIC]?

Provide:
- Strong consensus findings (cite multiple sources)
- Areas of uncertainty or debate
- Practical implications
- Confidence level for each conclusion
```

## Example Usage

### Topic: Remote Work Productivity

**Phase 1:**
```
Overview of remote work productivity research after 2020

Focus on:
- How productivity is measured
- Main findings (positive, negative, mixed)
- Leading researchers in this area
- Recent meta-analyses or reviews

Sources: Peer-reviewed journals, major research institutions
```

**Phase 2:**
```
Focus on measurement methodologies for remote work productivity

Find:
- Different metrics used (output, time, quality, etc.)
- Objective vs subjective measures
- Validity and reliability of each approach
- Limitations of each methodology

For each approach, cite specific studies with sample sizes.
```

**Phase 3:**
```
Compare findings from:
- Controlled experiments
- Natural experiments (pandemic-forced remote work)
- Longitudinal studies
- Cross-sectional surveys

For each type:
- Typical findings
- Methodological strengths
- Limitations
- Why results might differ

Highlight contradictions and explain possible causes.
```

**Phase 4:**
```
What aspects of remote work productivity are under-researched?

Identify:
- Understudied populations (e.g., specific industries)
- Long-term effects (> 2 years)
- Moderating factors not well understood
- Measurement gaps

Cite papers that acknowledge these limitations.
```

**Phase 5:**
```
Based on the research, what can we confidently conclude about remote work productivity?

Provide:
- High-confidence findings (supported by multiple rigorous studies)
- Medium-confidence findings (some evidence, needs more research)
- Low-confidence areas (contradictory or limited evidence)
- Practical implications for organizations
```

## Customization Tips

### For Technical Topics
- Add phase for implementation details
- Include code examples or technical specifications
- Focus on benchmarks and performance data

### For Business Topics
- Add market size and growth analysis
- Include competitive landscape
- Focus on ROI and business metrics

### For Academic Topics
- Emphasize methodology and rigor
- Include citation network exploration
- Focus on theoretical frameworks

---

## Quick Checklist

Before moving to next phase:
- [ ] Verified key claims with citations
- [ ] Checked for contradictions
- [ ] Noted confidence level
- [ ] Identified gaps or limitations
- [ ] Documented sources for later reference
