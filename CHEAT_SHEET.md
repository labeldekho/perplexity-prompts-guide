# 📋 Perplexity Prompts Cheat Sheet

Quick reference for effective Perplexity prompting. Print this out or keep it handy!

---

## 🎯 The 3-Part Formula

```
[SPECIFIC TOPIC] + [TIME/SOURCE CONSTRAINT] + [OUTPUT REQUIREMENT]
```

---

## 🔑 8 Core Strategies

| # | Strategy | Quick Tip | Example |
|---|----------|-----------|---------|
| 1 | **Add Context** | A few extra words = better results | "climate models" → "climate models for urban planning" |
| 2 | **Avoid Few-Shot** | Don't give examples | ❌ "like the Louvre" → ✅ "major art museums" |
| 3 | **Search Controls** | Filter date, source, depth | "after October 2024, from Reuters only" |
| 4 | **Multiple Perspectives** | Force triangulation | "Compare 3 peer-reviewed studies and highlight conflicts" |
| 5 | **Progressive Deepening** | Start broad, refine | Round 1: Overview → Round 2: Specific aspect |
| 6 | **Output Constraints** | Demand evidence | "Provide evidence for each claim with page numbers" |
| 7 | **Focus Modes** | Switch search behavior | Academic, Social, Finance, Video |
| 8 | **Spaces/Labs** | Reusable workflows | Create standing instructions for recurring tasks |

## ⚡ Quick Prompt Templates

### Research
```
[Topic] developments after [date], focusing on [source type]
```

### Competitive Intelligence
```
[Company]'s [aspect] compared to [competitors], using official sources only
```

### Academic
```
Peer-reviewed studies on [topic] from [date range], 
journals with impact factor > [number]
```

### Fact-Checking
```
Verify: "[claim]" - find original sources and check for contradictions
```

### News Monitoring
```
[Topic] coverage from [sources] in last [timeframe], 
highlight conflicting narratives
```

## 🎚️ Search Control Keywords

### Time Filters
- `after [date]`
- `before [date]`
- `between [date] and [date]`
- `in the last [X] days/weeks/months`
- `published in [year]`

### Source Filters
- `from [source names]`
- `using only [type of source]`
- `peer-reviewed sources only`
- `official announcements only`
- `exclude [source names]`

### Depth Controls
- `comprehensive analysis`
- `brief overview`
- `detailed breakdown`
- `surface-level summary`

## ✅ Do's and Don'ts

### ✅ DO

- ✅ Be specific with context
- ✅ Add time constraints
- ✅ Filter by source type
- ✅ Ask for multiple perspectives
- ✅ Demand citations and evidence
- ✅ Verify results independently
- ✅ Use progressive deepening
- ✅ Switch Focus modes strategically

### ❌ DON'T

- ❌ Use few-shot examples
- ❌ Write long, detailed instructions
- ❌ Trust single obscure sources
- ❌ Skip time constraints
- ❌ Forget to verify quotes
- ❌ Assume it's always right
- ❌ Use it for creative tasks
- ❌ Ignore citation quality

---

## 🚨 Hallucination Red Flags

Watch out for:
- 🚩 Single obscure blog as only source
- 🚩 No direct quotes or page numbers
- 🚩 Claims that seem too convenient
- 🚩 Contradictions between sources not mentioned
- 🚩 "According to experts" without names
- 🚩 Suspiciously perfect answers

**Always verify:** Click citations, cross-check with ChatGPT, search quotes directly

| Multi-source verification | Creative writing |
| Competitive intelligence | Summarization |
| News monitoring | Task planning |

## 💡 Pro Tips

1. **Start conversations with context**: "I'm researching X for Y purpose"
2. **Use follow-ups**: Build on previous responses progressively
3. **Combine with ChatGPT**: Research in Perplexity, analyze in ChatGPT
4. **Save good prompts**: Create Spaces for recurring workflows
5. **Check source quality**: Not all citations are equal
6. **Use Academic mode**: For high-precision queries
7. **Ask for conflicts**: "Highlight contradictions between sources"
8. **Demand specifics**: Page numbers, dates, exact quotes

---

## 🎯 One-Minute Prompt Upgrade

**Before sending any prompt, ask:**
1. Is it specific enough? (Add context)
2. Do I need recent info? (Add time filter)
3. Do I care about source quality? (Add source filter)
4. Do I need evidence? (Ask for citations)

**If you answered YES to any:** Revise your prompt!
