This guide provides battle-tested techniques, real-world examples, and reusable templates to help you become a Perplexity power user.

## 🎯 Key Differences: Perplexity vs ChatGPT

| Aspect | Perplexity | ChatGPT |
|--------|-----------|---------|
| **Knowledge Source** | Real-time internet search | Pre-trained model weights |
| **Best For** | Recent facts, citations, research | Reasoning, coding, creative tasks |
| **Prompting Style** | Short, specific, search-like | Detailed instructions, few-shot |
| **Output** | Cited sources, factual | Synthesized, creative |
| **Recency** | Always current | Knowledge cutoff date |

**Bottom line:** Use Perplexity for **researching**, ChatGPT for **reasoning**. They complement each other perfectly.

## 💡 Core Strategies at a Glance

1. **Add Context** - A little goes a long way
2. **Avoid Few-Shot** - Examples over-weight results
3. **Use Search Controls** - Filter by date, source, depth
4. **Request Multiple Perspectives** - Force triangulation
5. **Progressive Deepening** - Start broad, refine iteratively
6. **Specify Output Constraints** - Demand evidence and citations
7. **Use Focus Modes** - Academic, Social, Finance, etc.
8. **Create Spaces/Labs** - Reusable workflows for recurring tasks

## 📖 Example: Before & After

### ❌ Generic Prompt
```
climate models
```
**Problem:** Too vague, returns general information

### ✅ Optimized Prompt
```
climate prediction models for urban planning after 2023, 
focusing on peer-reviewed sources from Nature Climate Change or Science
```
**Result:** Precise, recent, authoritative sources with citations
