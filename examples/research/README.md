# Research Examples

Real-world prompts for academic and technical research tasks.

---

## Example 1: Literature Review

### Scenario
You're starting research on a new topic and need to understand the landscape.

### Prompt Sequence

**Round 1: Map the Field**
```
Overview of transformer architectures in natural language processing
after 2020, focusing on peer-reviewed papers from top-tier conferences
(NeurIPS, ICML, ACL, EMNLP)
```

**Round 2: Identify Key Papers**
```
What are the most-cited papers on transformer architectures from 2020-2024?
Include citation counts and main contributions of each.
```

**Round 3: Find Recent Developments**
```
What improvements to transformer architectures were published in 2024?
Focus on efficiency, scaling, or novel attention mechanisms.
Cite specific papers with publication venues.
```

**Round 4: Identify Gaps**
```
What limitations of current transformer architectures do researchers
acknowledge in recent papers?
What future research directions are proposed?
```

## Example 2: Methodology Comparison

### Scenario
You need to understand different approaches to solving a problem.

### Prompt
```
Compare methodologies for measuring developer productivity across
at least 3 peer-reviewed studies.

For each study:
- Sample size and selection criteria
- Metrics used (DORA, SPACE, etc.)
- Key findings
- Acknowledged limitations

Highlight where methodologies conflict and explain why.
```

### Why This Works
- Forces comparison of approaches
- Focuses on methodology, not just conclusions
- Reveals why studies might contradict
- Identifies most rigorous approaches

## Example 3: Finding Primary Sources

### Scenario
You found a claim in a secondary source and need the original.

### Prompt
```
Find the original source for this claim:
"Remote workers are 13% more productive than office workers"

I need:
- Original study or report
- Exact methodology and sample
- Publication date and venue
- Whether this finding has been replicated
- Any critiques or contradictory findings
```

## Example 4: Tracking Research Evolution

### Scenario
Understanding how thinking on a topic has changed.

### Prompt Sequence

**Round 1: Historical Baseline**
```
What did researchers believe about [topic] in 2015?
Cite major papers and summarize consensus views.
```

**Round 2: Identify Shifts**
```
How did understanding of [topic] change between 2015 and 2020?
What new evidence or methods drove these changes?
```

**Round 3: Current State**
```
What is the current consensus on [topic] as of 2024?
Cite recent review papers or meta-analyses.
```

**Round 4: Future Directions**
```
What open questions remain about [topic]?
What future research do recent papers call for?
```

## Example 5: Cross-Disciplinary Research

### Scenario
Finding how different fields approach the same problem.

### Prompt
```
How do computer scientists, psychologists, and neuroscientists
each approach the problem of [topic]?

For each field:
- Main frameworks or theories used
- Typical methodologies
- Key findings unique to that field
- Opportunities for cross-disciplinary synthesis

Cite representative papers from each field.
```

## Example 6: Replication and Robustness

### Scenario
Checking if findings are robust and replicated.

### Prompt
```
Has the finding "[specific claim]" from [paper] been replicated?

Find:
- Replication attempts (successful and failed)
- Meta-analyses that include this finding
- Critiques of the original methodology
- Current consensus on robustness

Cite specific papers for each.
```

## Example 7: Finding Datasets

### Scenario
You need datasets for your research.

### Prompt
```
What publicly available datasets exist for [research topic]?

For each dataset:
- Size and composition
- Collection methodology
- Citation (if from a paper)
- Access method (URL, API, etc.)
- Known limitations or biases

Focus on datasets used in peer-reviewed research after 2020.
```

## Example 8: Conference Proceedings Search

### Scenario
Finding cutting-edge research from specific venues.

### Prompt
```
What papers on [topic] were presented at [conference] in [year]?

For each relevant paper:
- Title and authors
- Main contribution
- Key results
- Whether it won any awards
- Citation count (if available)

Prioritize papers with novel approaches or strong empirical results.
```

## Example 9: Researcher Identification

### Scenario
Finding experts in a specific area.

### Prompt
```
Who are the leading researchers on [specific topic]?

For each researcher:
- Institutional affiliation
- H-index and total citations
- 3-5 most influential papers on this topic
- Current research focus
- Recent publications (last 2 years)

Focus on researchers actively publishing in top venues.
```

## Example 10: Systematic Review Approach

### Scenario
Conducting a mini systematic review.

### Prompt Sequence

**Round 1: Define Scope**
```
Find all peer-reviewed studies on [topic] published between [dates]
in journals with impact factor > [threshold].

Provide:
- Total number of studies found
- Main journals represented
- Geographic distribution of research
```

**Round 2: Extract Findings**
```
For the studies found, what are the main findings?
Group by:
- Positive effects
- Negative effects
- Null results
- Mixed or context-dependent results
```

**Round 3: Assess Quality**
```
What are the methodological strengths and limitations across these studies?
- Common sample sizes
- Typical study designs
- Control variables used
- Acknowledged limitations
```

**Round 4: Synthesize**
```
Based on these studies, what can we confidently conclude about [topic]?
What remains uncertain or contested?
Where is more research needed?
```

## Tips for Research Prompts

### ✅ DO:
- Use Academic Mode
- Specify peer-reviewed sources
- Ask for citation counts
- Request methodology details
- Look for contradictions
- Check for replications

### ❌ DON'T:
- Accept single-study claims
- Ignore methodology
- Skip checking impact factors
- Trust preprints without verification
- Forget to check for retractions
