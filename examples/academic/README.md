# Academic Examples

Prompts for scholarly research, literature reviews, and academic writing.

---

## Example 1: Finding Systematic Reviews

### Prompt
```
Find systematic reviews or meta-analyses on [topic]
published in last 5 years in journals with impact factor > 5.

For each:
- Number of studies included
- Main findings and effect sizes
- Quality assessment approach
- Acknowledged limitations
- Future research recommendations
```

---

## Example 2: Citation Network Exploration

### Prompt Sequence
```
Round 1: Find the most-cited paper on [topic] from last 5 years

Round 2: What papers cite this work? Summarize how they build on or critique it.

Round 3: What foundational papers does this work cite?

Round 4: Are there competing frameworks? Find papers proposing alternatives.
```

---

## Example 3: Methodology Deep Dive

### Prompt
```
How do researchers measure [construct/variable] in [field]?

Find at least 5 different measurement approaches from peer-reviewed studies.
For each:
- Measurement instrument or method
- Validity and reliability evidence
- Advantages and limitations
- Citation for original development
```
