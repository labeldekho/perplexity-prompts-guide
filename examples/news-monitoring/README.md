# News Monitoring Examples

Prompts for tracking current events, trends, and breaking news.

---

## Example 1: Multi-Source News Tracking

### Prompt
```
[Topic] coverage from Reuters, AP, Bloomberg, and NYT
in last 7 days.

For each major development:
- What happened (facts only)
- When it was reported
- How different outlets framed it
- Any conflicting details between sources
```

---

## Example 2: Narrative Evolution Tracking

### Prompt Sequence
```
Round 1: How was [event] initially reported? (first 24 hours)

Round 2: How did the narrative change after 1 week?

Round 3: What new information emerged? What was corrected?

Round 4: What's the current consensus understanding?
```

---

## Example 3: Fact-Checking Breaking News

### Prompt
```
Verify this claim: "[breaking news claim]"

Find:
- Original source of the claim
- Corroborating sources (at least 2 independent)
- Any contradictions or corrections
- Official statements if applicable
- Fact-checker assessments

Note: Prioritize established news organizations.
```
