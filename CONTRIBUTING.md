# Contributing to Perplexity Prompts Guide

Thank you for your interest in contributing! This guide helps researchers, analysts, and curious minds get the most out of Perplexity AI.

## How to Contribute

### 1. Share Your Prompts & Examples

We're always looking for real-world examples that demonstrate effective prompting strategies.

**What makes a good contribution:**
- ✅ Real prompts you've used successfully
- ✅ Before/after comparisons showing improvement
- ✅ Specific use cases with context
- ✅ Screenshots or citations (when appropriate)

**How to submit:**
1. Fork this repository
2. Add your example to the appropriate directory in `examples/`
3. Follow the template format (see existing examples)
4. Submit a pull request with a clear description

### 2. Improve Documentation

Found a typo? Have a clearer way to explain a concept? Want to add a missing strategy?

- Edit the relevant markdown file
- Ensure formatting is consistent
- Add citations for factual claims
- Submit a PR

### 3. Create New Templates

If you've developed a reusable prompt workflow, share it!

- Add it to the `templates/` directory
- Include clear instructions and examples
- Explain when to use this template
- Provide variations for different scenarios

### 4. Report Issues

Found something that doesn't work or needs updating?

- Open an issue with a clear description
- Include examples if applicable
- Tag appropriately (bug, enhancement, question)

## Contribution Guidelines

### Format Standards

**Markdown files should:**
- Use clear, descriptive headings
- Include code blocks for prompts (use triple backticks)
- Add links to sources when referencing external content
- Keep lines under 120 characters when possible

**Example format:**
```markdown
## Strategy Name

**Concept:** Brief explanation

**Example:**
```
Your prompt here
```

**Result:** What this achieves
```

### Quality Standards

- **Accuracy**: Verify your examples work with current Perplexity
- **Clarity**: Write for beginners, even for advanced topics
- **Completeness**: Include context, not just isolated prompts
- **Originality**: Share your own experiences, not copied content

### Code of Conduct

- Be respectful and constructive
- Focus on helping others learn
- Give credit where credit is due
- No spam or self-promotion

## Questions?

Open an issue with the `question` label, and we'll help you out!
